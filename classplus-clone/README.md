# Classplus Clone

This is a clone of the Classplus educational platform landing page and features, built with HTML, Tailwind CSS, Google Fonts, and Font Awesome.

## Project Structure

- `index.html` - Main HTML file
- `css/styles.css` - Custom CSS styles
- `js/scripts.js` - Custom JavaScript

## Setup

Open `index.html` in a browser or serve with a local development server to view the site.

## Features

- Responsive design with Tailwind CSS
- Multi-section layout including live teaching, recorded courses, payment gateway demo, and student interaction
- Uses Google Fonts and Font Awesome for typography and icons
